# Interactive Responsive Ecommerce Product Page

A polished front-end ecommerce portfolio project built with **HTML, CSS, and vanilla JavaScript**.

## Live Features

- Responsive desktop, tablet, and mobile layout
- Real product photography
- Dynamic colour-variant galleries
- Main, side/back, and detail image views for each colour
- Product image zoom
- Size selector
- Quantity controls
- Add-to-bag functionality
- Slide-out cart drawer
- Cart quantity editing and item removal
- Dynamic subtotal calculation
- Cart persistence with `localStorage`
- Wishlist toggle
- Search overlay with live filtering
- Product accordions
- Size-guide modal
- Mobile navigation
- Related-product quick view
- Related-product quick add
- Reviews section
- Demo Buy Now / Checkout flow
- Keyboard Escape support for overlays

## Technologies

- HTML5
- CSS3
- Vanilla JavaScript
- Responsive Web Design
- CSS Grid
- Flexbox
- DOM manipulation
- Browser localStorage
- Event handling
- Basic UI state management
- Accessible ARIA states
